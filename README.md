## Workshop Nid Gaming Sharp Arcade

Bienvenue à vous dans ces deux jours de Nid Gaming 🙂

L’idée d’un nid est de voir si vous aimez le jeu vidéo et la programmation avant de vous lancer dans une formation longue de 6 mois intenses, de deux ans de galère et de 10 ans de “crunch”, suivis de 20 ans de prise de niveaux pour devenir un magicien renommé.

Plus sérieusement, le monde du jeu vidéo est largement atteignable et il y a de l’emploi autour du jeu vidéo.
Mais effectivement, ce métier nécessite d’apprendre continuellement pendant **toute votre vie**.

C# n’est pas un prérequis à la formation gaming…
Mais la qualité numéro une dans le domaine est de s’autoformer.
Donc venir sans avoir touché à C#, c’est très risqué pour vous.

La formation est là pour vous **accélérer** l’apprentissage
et vous habituer à travailler en groupe.

Mon but :

* Vous faire plaisir en vous montrant comment relier vos jeux à une borne d’arcade.
* Réviser un peu C# avec vous pour vous aider dans votre progression.

Le pire que vous puissiez faire est d’attendre la formation longue.
Préparez-vous en révisant vos points faibles en C#.
Et familiarisez-vous avec Git et GitHub.

Sur ce, allons apprendre à relier tout ça.
